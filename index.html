Truck drivers report status by voice. Dispatch gets it instantly.

Drivers send a WhatsApp or SMS message, or a voice note. The bot understands it, updates your ERP, and replies with a clear confirmation.

How it works View code on GitHub
Dispatch Assistantdemo
Hi driver! Send me your status, for example “Delayed 45 minutes, heavy traffic”.

This demo runs only in your browser with simple keyword matching. The real bot uses Whisper and GPT-4o-mini on a Flask server.

How it works

One message goes through five steps in a few seconds.

  1. Driver sendsA text or a voice note on WhatsApp or SMS.
  2. Twilio forwardsThe message reaches the Flask webhook, which checks it really came from Twilio.
  3. Voice becomes textOpenAI Whisper transcribes voice notes.
  4. Intent is foundGPT-4o-mini reads the text, including Hindi, Marathi and Hinglish.
  5. ERP is updatedThe driver gets a confirmation message back.

What the bot understands

One message can contain more than one update, such as “Reached gate 3 and starting my break”.

Delay

How long and why. “2 ghante late, tyre puncture” becomes 120 minutes, vehicle issue.

Rest break

Start and end of a break, so rest hours are on record.

Gate check-in

Arrival at a gate, plant, warehouse or yard, with the gate number.
